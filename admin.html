How do I get a token?
  1. On GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Under "Repository access", choose "Only select repositories" and pick just this one repo.
  3. Under "Permissions", set Contents to Read and write. Leave everything else as No access.
  4. Generate the token and copy it — GitHub only shows it once. Paste it above.
  5. Treat it like a password. If it's ever exposed, revoke it from the same GitHub settings page.
